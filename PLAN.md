# BDS110 Showcase – gjennomføringsplan

1. Les primærkilden og relevante deler av kursmaterialet. Fullført.
2. Bygg en lokal, tilgjengelig prototype med tre hovedvisninger og felles avviksdata.
3. Test flyt, kontrollene, nettbrett/mobil og laptop; inspiser faktiske skjermbilder.
4. Lag A2-plakat med skjermbilder fra den ferdige prototypen. Kontroller PDF og PNG.
5. Lever produksjonsmappe, kildekode, tester, kildegrunnlag og norsk presentatørveiledning.

Teknisk valg: HTML, CSS og JavaScript uten kjøretidsavhengigheter. En fil kan åpnes direkte fra disk. Ingen data sendes ut. React/Vite er vurdert, men tilfører lite verdi til denne avgrensede offline-demonstrasjonen.
